# آزمون مستقل YouTube Best Practices

این ابزار API همین پروژه را آزمایش می‌کند، نه API سایت benchmark را.
briefها، متن‌های مرجع و rubric دقیق ToneBench خصوصی‌اند؛ بنابراین نتایج این ابزار
**امتیاز رسمی ToneBench، Writing Score یا Writing Elo نیستند** و نباید کنار
رتبه‌های سایت به‌عنوان نتایج قابل‌مقایسه منتشر شوند.

منابع روش‌شناسی، بررسی‌شده در ۲۰۲۶-۱۰-۲۵:

- https://benchmark.towardsai.com/
- https://benchmark.towardsai.com/methodology.html

بر اساس توضیح عمومی سایت، محور YouTube Best Practices به CTA متناسب آغاز،
سؤال پایانی آینده‌نگر، طرح و پرداخت open loop و بازگرداندن توجه مربوط است.
اینجا یک rubric مستقل پنج‌بخشی داریم: همان چهار مورد و پیشروی منسجم روایت.
هر بخش ۰ تا ۴ می‌گیرد؛ مجموع در ۵ ضرب می‌شود و امتیاز محلی ۰ تا ۱۰۰ می‌دهد.
این وزن‌دهی ساختهٔ این آزمایشگاه است، نه فرمول داخلی سایت.

## اجرای کوتاه، بدون وابستگی Python اضافی

از ریشهٔ پروژه، با سرویس محلیِ روشن:

```bash
python3 examples/youtube_benchmark.py \
  --model gemini-4-argon --thinking 1 \
  --case axis --drafts 1 \
  --output artifacts/youtube/argon-low-smoke
```

بدون `--judge-model` فقط متن و اندازه‌گیری ذخیره می‌شوند؛ امتیاز `null` است.
سه brief اصلی خودمان دربارهٔ محور/تداوم، نورپردازی تک‌چراغ و طراحی صدا هستند.
این‌ها داده‌های اختصاصی ToneBench یا تقلید صدای یک شخص مشخص نیستند.
زبان پیش‌فرض انگلیسی است؛ برای فارسی `--language Persian` بدهید.
سطح فکر Gemini: `1=LOW`، `2=MEDIUM`، `3=HIGH`؛ Argon سطح MINIMAL را قبول نمی‌کند.

## پنج draft برای هر سه موضوع، با داور مستقل

```bash
python3 examples/youtube_benchmark.py \
  --base-url http://127.0.0.1:3346 \
  --model gemini-4-argon --thinking 3 \
  --judge-model chatgpt/gpt-5.6-thinking-off \
  --drafts 5 --output artifacts/youtube/argon-high-judged
```

این اجرا ۱۵ درخواست تولید و ۱۵ درخواست داوری دارد. ChatGPT باید session آماده
داشته باشد؛ `--browser-id` اختیاری و فقط مخصوص درخواست‌های ChatGPT است.
مدل داور Gemini هم مجاز است، ولی داوری با همان مدل/خانواده سوگیری دارد.
برای مقایسهٔ LOW/HIGH پوشه‌های خروجی جدا و یک داور ثابت استفاده کنید.
سطح فکر داور Gemini جداگانه با `--judge-thinking` تعیین می‌شود و پیش‌فرض آن
`2=MEDIUM` است؛ تغییر فکر نویسنده، سطح فکر داور را تغییر نمی‌دهد.
به‌جز پارامتر فکر، brief و دستور نوشتن بین اجراها ثابت می‌مانند.

درخواست Gemini از مسیر Vertex-compatible و درخواست ChatGPT از
`/v1/chat/completions` می‌رود. هیچ ابزار وب یا جست‌وجویی به مدل داده نمی‌شود.
مسیر خروجی HTTP به gateway محلی است؛ proxy خروجی upstream را تنظیمات خود سرویس
تعیین می‌کند و این اسکریپت آن را تغییر نمی‌دهد.

## خروجی و ادامهٔ اجرا

- `config.json`: تنظیمات و fingerprint متن آزمون برای جلوگیری از اختلاط نتایج.
- هر پوشهٔ موضوع/draft: prompt، `script.md`، پاسخ کامل و مصرف توکن.
- در حالت داوری: prompt داور، پاسخ خام، نمره و شاهدهای متنی هر معیار.
- `summary.json`: نتایج، میانگین محلی و انحراف معیار نمونه؛ نه بازهٔ اطمینان.

اجرای مجدد همان فرمان، draftهای کامل را skip می‌کند. اگر داوری شکست خورده باشد،
متن تولیدشده دوباره مصرف می‌شود و دوباره تولید نمی‌شود. در اولین خطا، از جمله
429، اجرا متوقف می‌شود؛ retry خودکار یا چرخش حساب برای عبور از محدودیت نداریم.
متن truncateشده یا نمرهٔ خارج از بازه یا شاهدی که عیناً در متن نیست پذیرفته نمی‌شود.
فایل‌های پاسخ ممکن است metadata حساب/پروفایل داشته باشند؛ عمومی منتشرشان نکنید.

شمارش واژه تقریبی و با حذف `[SHOW: ...]` است. نمرهٔ خودکار برای صحت فنی،
کیفیت بصری، slop یا پیش‌بینی retention واقعی محاسبه نمی‌شود. شاهد لفظی صحیح
هم تضمین نمی‌کند قضاوت داور درست باشد؛ بازبینی انسانی لازم است.

## brief اختصاصی و تست‌ها

با `--cases path/to/cases.json` آرایه‌ای با فیلدهای `id`، `title`، `brief`،
`target_words` و `research` (لیست واقعیت‌های مجاز) بدهید؛ قالب پیش‌فرض در
`examples/youtube_eval/cases.json` است. `--case` قابل تکرار است.

```bash
python3 -m unittest discover -s scripts -p 'test_youtube_benchmark.py' -v
```

## نتیجهٔ smoke واقعی، ۲۰۲۶-۱۰-۲۵

دو تولید مستقل Argon LOW برای موضوع `axis` موفق شدند. اولی ۸۷۹ واژه داشت و
بدون داور بود. دومی با داور `chatgpt/gpt-5.6-thinking-off` امتیاز محلی ۹۵/۱۰۰
گرفت: چهار معیار ۴/۴ و سؤال پایانی ۳/۴، چون دو پرسش را در یک جمله آورده بود.
شاهدهای داور عیناً در متن وجود داشتند و اعتبارسنجی شدند.

متن دوم ۹۲۸ واژه در برابر هدف ۶۵۰ واژه داشت، یعنی ۴۲٫۸٪ اضافه‌طول؛ این مشکل
در نمرهٔ محدود YouTube practices محاسبه نمی‌شود و باید جدا دیده شود.
مصرف اعلام‌شدهٔ تولید: ۳۹۴ توکن ورودی و ۱۳۳۷ خروجی، زمان ۲۵٫۱۱ ثانیه.
جزئیات در `artifacts/youtube/argon-low-judged-20261025/summary.json` موجود است.
این تنها یک موضوع با یک داور است و رتبه‌بندی یا برآورد آماری کیفیت مدل نیست.
۱۲ تست مستقل پاس شدند؛ پوشش خطوط کد جدید با coverage برابر ۸۹٪ بود.
